# 角色精修流程

這份文件記錄阿澄從 v1 精修到 v2 的流程。這次是演練，目的是把做法固定下來，之後正式開發新角色或改版時照著走。

## 流程

1. **定契約，不動編舞**
   每個分鏡都只透過 `Kid` 抽象類別的 `Pose()`、`Hand()` 與 `Hide()` 操作角色。新版本必須沿用同一套局部座標：
   - 腳底在原點
   - 頭部中心在 (0,45)
   - 前臂支點在 (7.5,31)，手臂長 16.5

   這樣換版本時，分鏡程式和星星黏在手上的位置都不用改。
2. **配色寫成資料**
   顏色放在 `stories/<故事>/characters/<角色>.json`，Unity 讀取時，缺少的欄位使用程式內的預設值。調色只需要改 JSON，重新渲染即可，不用改程式。
3. **先看設定表，再進故事**
   執行 `scripts/character_sheet.sh star_city`，輸出 `output/star_city/characters/cheng_sheet.png`。設定表上排是 v1，下排是 v2，依序排出故事實際用到的姿勢：待機、走路兩格、伸手、踮腳舉高、坐下、眨眼。一次 Unity 批次大約 4 秒，可以快速來回修改。
4. **用旗標並行，不覆蓋成品**
   在 `story.py` 加上 `--character v2` 就會改用新角色，預設仍是 v1。先用 `--stills` 輸出兩個版本的同一批時間點，放到 `output/<故事>/compare/<版本>/<格式>/` 做比較。
5. **交給另一個代理比對**
   比對 v1 和 v2 的靜態圖時，重點有四項：角色是否清楚可見、星星是否仍在手上、圖層順序是否正確、零件是否脫落。確認沒問題後，才把預設值改成 v2，並重新產出影片。
6. **由使用者定案**
   使用者看過設定表和影片之後，才把新版設為預設。

## v2 做了什麼

- **描邊**：每個零件都多畫一個外擴版本當描邊，放在填色下方一層。軀幹等大零件的描邊統一放在最底層，所以只會描出外輪廓，內部的接縫不會出現線條。手臂和帽子的描邊則只比自己低一層，所以疊在身體前面時也有輪廓。
- **層次**：袍子使用頂點色漸層，加上腰帶、扣環，以及下擺的金邊和星點。
- **臉部**：加了後腦的頭髮、瀏海、鼻子、眼睛反光和微笑。
- **配件**：藍色圍巾和圍巾尾巴，帽子有星形徽章，帽尖會下垂擺動，另外加了後側手臂。
- **待機動作**：會眨眼（每 3.7 秒一次，每三次中有一次眨兩下）、呼吸、頭部微晃，帽尖和圍巾會跟著步伐擺動。這些都是時間的純函數，同樣的時間點永遠算出同樣的畫面。

## 踩過的坑

- **外擴描邊**：做法是從重心向外推，只適用於凸多邊形。凹的形狀要拆成幾個凸塊來畫。
- **分段零件的接縫**：帽尖是獨立零件，旋轉時會和帽身之間露出縫隙。解法是把帽尖的底邊加寬，並往下延伸壓住帽身。
- **配件比例**：圍巾太大太亮時會搶走臉部的焦點，還會蓋住嘴巴。配件應該比主體低調，讓臉保持是最亮、最清楚的地方。
- **細節不一定看得到**：在影片裡，角色只佔畫面高度的一成左右，太細的細節會看不到。判斷要以故事實際取景下的靜態圖為準，不要只看放大的設定表。

## 之後正式開發可以沿用

- **新角色**：先寫契約，也就是局部座標和手的位置，再畫設定表，最後才放進故事。
- **更精緻的角色**：如果之後要換成 AI 生成或手繪的分層圖片，可以用 Unity 2D Animation 的骨架，或者把每個零件換成 Sprite。只要沿用同一套 `Kid` 契約，分鏡程式就不用動。
